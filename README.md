## Installation

Add the package to `Package.swift`:

```swift
.package(url: "https://github.com/__OWNER__/gpx-swift.git", from: "0.1.0")
```

Then add `"GPXSwift"` to your target's dependencies.

## Quick start

```swift
import GPXSwift

let library = GPXSwift()
print(library.greeting())
```
